# 主要機能詳細

MarumaCamに搭載されている主要な撮影制御機能について解説します。

## 1. 瞳孔間距離 (IPD) 調整
ステレオカメラのベースライン（左右のカメラの間隔）を調整し、立体感の強弱を制御します。
- **効果**: 撮影対象のサイズや奥行き感に合わせて、最適なステレオ感を設定可能です。
- **操作**: VRChat 内の Expression Menu から調整可能です。

## 2. 空間固定 (World Fixed)
カメラをワールドの座標系に固定し、アバターの動きに関わらず一定の位置・角度を維持します。
- **効果**: 定点撮影や第三者視点での撮影をサポートします。
- **操作**: メニューから ON/OFF を切り替え可能です。

## 3. リアルタイムプレビュー
撮影中の VR180 映像をアバターの前面や特定の位置に表示し、構図を確認できます。
- **効果**: 撮影ミスを防ぎ、正確な映像制作を支援します。
- **コンポーネント**: `PreviewBox.prefab` を使用して制御されています。

## 4. グローバル/ローカル切り替え (Camera Switch)
カメラの動作モードをグローバル（全ユーザー共有）またはローカル（自分のみ）で切り替える機能です。
- **効果**: 他のユーザーの視界に干渉せず撮影を行ったり、逆に共有したりすることができます。

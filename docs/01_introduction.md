# MarumaCam 概要

MarumaCamは、VRChatのアバターおよびUnityプロジェクト向けに設計された高精度VR180立体視映像システムです。

## プロジェクトの目的
VRChat内での高品質なVR180撮影およびリアルタイムプレビューを実現し、没入感のある映像体験をアバターギミックとして提供することを目的としています。

## 主な特徴
- **高解像度**: 独自の4分割アトラスマッピングによる高精細な映像。
- **Modular Avatar対応**: 面倒なAnimator設定を自動化し、ドラッグ＆ドロップでの導入が可能。
- **高度な制御**: IPD調整や空間固定などの撮影機能を搭載。
